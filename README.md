# 🍃 Power BI Project: Tea Production and Export Analysis
Used "Tea Exporters Association of Sri Lanka – Annual Production Exports" statistics. 

## 🧩 Project Overview

This Power BI project visualizes **Tea Production and Export Data** in Sri Lanka to generate meaningful insights through interactive visualizations.  
The dashboard includes the following charts:

- 📊 **2 Clustered Column Charts**
- 🌊 **1 Stacked Area Chart**
- 🍩 **1 Donut Chart**

---

## 🚀 Step-by-Step Guide

### 1️⃣ Create and Set Up the Project

1. **Open Power BI Desktop** and create a new project by selecting **“Blank Report.”**
2. **Rename** the project and **save** it in a new folder.
3. **Add the data files** (Excel files for Tea Production and Tea Exports) to the same folder.
4. Go back to Power BI and click **“Get Data from Another Source.”**
5. Upload the files one by one, selecting the correct file type for each.
6. In this case:
   - Uploaded one **Excel file** for Tea Production.
   - Uploaded another **Excel file** for Tea Exports.
   - Each file was **transformed before loading**.
7. *(Alternative method)* — You can also upload both files first, load them, and then transform them one by one.

---

## 🧮 Data Transformation Steps

### 🔹 1. Tea Production Excel Data File Transformation

Perform the following transformations:

- Change the **Year** column data type from **Text → Date**.
- Change all other columns from **Text → Whole Number**,  
  since tea production is measured in **metric tons**.

---

### 🔹 2. Tea Exports Excel Data File Transformation

Perform the following transformations:

- Change the **Year** column data type from **Text → Date**.
- Change all other columns from **Text → Whole Number**,  
  since tea exports are measured in **metric tons**.

---

## ✅ Apply and Load Data

10. Once both transformations are done, click **Close & Apply**.  
11. Power BI will automatically detect **relationships between the tables** upon loading,  
    so manual merging is not required.

---

## 📊 Visualization and Insights

12. Create insights by opening the **Visualizations** tab and selecting the desired features from each table’s columns.  
    You can add multiple report pages as needed.

**Example visualizations:**
- 📊 Chart with Slicer  
- 📋 Tables with Quick Measures  
- 🗺️ Map Chart  
- 📉 Line Chart  
- 📍 KPI Chart (for dashboards)

**Visuals used in this project:**
- 2️⃣ **Clustered Column Charts**
- 1️⃣ **Stacked Area Chart**
- 🍩 **Donut Chart**

These visuals provide clear comparative insights into **tea production** and **tea exports** trends.

---

## 💾 Save and Publish

13. After creating your visuals and completing the dashboard:
- Click **Save** to store your Power BI project locally.
- Click **Publish** to upload your report to the **Power BI Service**.
- Share your interactive report on the web or with team members.
